朋友问我："你连服务器都没租，这网站是怎么跑起来的？"

答案有点扫兴：**这个网站没有服务器。**

准确地说，没有一台属于我的、一直开着的机器。这里所有的页面，都是我在自己的电脑上生成好一堆 HTML 文件，然后把它们推到 GitHub 上。GitHub 负责把这些文件放到离读者最近的节点上发出去，就这么简单。

<!-- more -->

## 为什么是静态站

动态网站（比如 WordPress）需要一台机器常驻，跑 PHP、连数据库、处理登录和评论。静态站不需要：所有页面在"生成"那一刻就已经是成品，服务器只负责把文件递出去。

代价是它不会"算"——不能登录、不能按用户显示不同内容、不能现场写数据库。好处也很明显：

- 不用租服务器，不用管运维、备份、安全补丁
- 打开速度快，没有任何后端查询
- 文章就是 Markdown 文件，全在我的硬盘上，不怕平台倒闭

对"写点东西、留个档"这个需求来说，静态站是性价比最高的方案。

## 为什么现在开始写

读研之后，每天接收的东西太多了：论文、代码、组会、还有一堆想不明白的问题。看的时候觉得懂了，过两个月再看，只剩下"我好像在哪见过"。

写作是唯一能验证"我真的懂了"的方式。讲不清楚的地方，就是没懂的地方。

所以这个博客主要放三类东西：

1. **学习笔记**——脑机接口、fMRI 解码、机器学习，以及绕不开的数学
2. **踩坑记录**——那些折腾了半天、最后发现只是少了一个引号的问题
3. **一些想法**——读书、升学、以及偶尔的自我怀疑

写得好不好另说，先写起来。

## 技术栈

- **Hexo**：静态博客生成器，把 Markdown 编译成 HTML
- **Fluid**：主题，简洁、中文友好
- **GitHub Pages**：免费托管，也就是开头说的"不存在的服务器"

整个流程就三步：写 Markdown → `hexo generate` → `git push`。
